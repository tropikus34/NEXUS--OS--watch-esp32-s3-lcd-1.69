# NEXUS OS 6.9.4 — исправления питания и экрана

## Что изменено
1. **Старая картинка при включении** (`NexusPower.h → wakeDisplay`): SLPOUT → догон часов → отрисовка → отправка кадра в GRAM → DISPON → подсветка. Подсветка включается последней.
2. **Сон экрана**: при гашении DISPOFF + **SLPIN (0x10)** вместо одного DISPOFF (~5–8 мА экономии).
3. **ШИМ подсветки** полностью отключается (`ledcDetach` + низкий уровень + `gpio_hold`), иначе LEDC блокирует light sleep.
4. **Кнопка будит по прерыванию**: при выключенном экране `loop()` спит на `ulTaskNotifyTake` до следующей секунды/нажатия, а не крутится каждые 20 мс. GPIO0 также источник пробуждения из light sleep.
5. **Частичная отправка кадра** (`NexusFrame.h`): передаются только изменившиеся строки; если кадр не изменился — шина не трогается.
6. **Датчик движения** при выключенном шагомере опрашивается раз в 2 с вместо 250 мс.
7. **Сборка с light sleep**: `sdkconfig.defaults` + `platformio.ini` (pioarduino, Arduino + ESP-IDF). Без этого в готовом ядре Arduino сон невозможен — команда статуса покажет `REASON=PM_NOT_BUILT`.

## Проверка
- Отправьте команду статуса при погашенном экране: ожидается `PM=1 TICKLESS=1 BT_MODEM=1`, `CPU` 40–80.
- Замер тока при выключенном экране и подключённом телефоне: цель 2–5 мА (было ~25–40 мА).
