# NEXUS OS 6.9.3 Sport

Для Waveshare ESP32-S3-LCD-1.69 V2, ST7789 240×280, управление одной BOOT.
Восстановленная реализация по присланному изображению и списку задач на основе архива 6.8 Glass. Исходников незапакованной версии Lovable в присланном архиве не было.

Изменения 6.9.3: модуль питания выделен в NexusPower.h, события батареи объединены с общей отрисовкой. Карта проекта: `docs/PROJECT_MAP_RU.md`.

Сначала прочитайте `docs/AUDIT_6_9_1_RU.md`: исправления питания, диагностика и ограничения проверки.

Актуальные изменения питания: `docs/RELEASE_6_9_3_RU.md`. Сохранённая ёмкость не перезаписывается: если ранее было 320, установите 600 в студии вручную.

## Установка
1. Распакуйте весь архив. Откройте `NEXUS_OS_6_9_3/NEXUS_OS_6_9_3.ino`. Все заголовки должны остаться рядом.
2. Используйте прежние рабочие настройки ESP32-S3, размера flash, разделов, PSRAM и USB CDC. Библиотеки: Arduino_GFX_Library, ChronosESP32 и совместимая с ним NimBLE-Arduino 2.x. Не очищайте всю flash при обычном обновлении. Готового бинарного файла нет: аппаратная сборка здесь не выполнялась.
3. После загрузки закройте Serial Monitor, откройте `NEXUS_Studio.html` в настольном Chrome/Edge, подключите USB. Если браузер запрещает Web Serial для локального файла, запустите в папке `python3 -m http.server 8000 --bind 127.0.0.1` и откройте `http://localhost:8000/NEXUS_Studio.html`.
4. Версия в студии после подключения — 6.9.3. Сначала сохраните резервную копию текущего проекта.
5. Оформление → тема → вид. Для встроенных циферблатов выключите свободную раскладку OSD. Пользовательская палитра имеет приоритет над встроенными цветами: отключите её для вида как в атласе. Фон-фотография тоже сохраняется; при необходимости отключите её.
6. Для энергопрофиля: «Батарея и энергия» → «Подготовить профиль 4 дня» → «Применить всё». Это настройки, а не обещание срока работы.

## Циферблаты
Темы: ONYX, AURUM, GLACIER, EMBER, NEBULA, VOLT, VAULT.
Виды: Numix, Track, Rings, Latte, Poster, Terminal, Стрелочный, Классический.
Индексы тем сохранены: ATELIER становится VOLT, VECTOR — VAULT. Виды 0–5 теперь спортивные, 6 — стрелочный, 7 — классический. Сохранённый индекс выбирает новую композицию; старое изображение не сохраняется автоматически.

Два нижних поля остаются настраиваемыми; доступны секунды, дата, верхняя строка, шесть цветов, радиус карточек, фотофон и OSD с перетаскиванием. Встроенные дуги и цифры не являются отдельными перетаскиваемыми объектами.

`Preview/All_56_Faces.png` — рендер настоящих C++ функций на компьютере с демонстрационными входными данными. HTML-предпросмотр приблизительный и также использует демонстрационные данные; это подписано в интерфейсе. Прошивка использует данные устройства. Датчика пульса нет: пульс не отображается. Дистанция и калории — оценки; без параметров тела/длины шага показан прочерк.

`Themes/*.nexus` — полные стартовые проекты, заменяют также настройки из базового профиля; перед импортом сохраняйте свой проект. `Themes/*.nxtheme` — совместимый старый формат для палитры и темы, сохраняет текущий вид/часть настроек. Обе группы имеют новые цвета.

## Проверки и ограничения
14 наборов C++ тестов с ASan/UBSan и 4 сценария интеграции HTML с реальным обработчиком команд через макеты оборудования пройдены. См. `docs/TEST_REPORT_RU.md` и `tests/power693_host_checks.log`.
Реальные Arduino-сборка, USB/BLE, экран и потребление платы не проверены. Поддержка автосна зависит от собранного ядра и драйверов. 4 дня на 600 мА·ч остаются целью, а не измеренным результатом.

Сохранены существующие функции: пять будильников, таймер, история сообщений, настройки звука/DND, персональные параметры активности, семь специализаций, восстановление связи, загрузка фона с CRC и резервные копии.
Старые описания сохранены в Reference/Before_6_9; при расхождении используйте этот README и docs/POWER_TARGET_RU.md.
