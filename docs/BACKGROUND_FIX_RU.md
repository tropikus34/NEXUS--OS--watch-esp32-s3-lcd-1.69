# Фон не загружается / экран мигает — версия 6.7.0

На снимке пользователя внизу студии видна ошибка `ERR NO_FILESYSTEM`. Прошивка отказалась принимать изображение, потому что LittleFS не готова. Изображение в HTML — локальный предпросмотр, оно ещё не на часах.

## Что делать

1. До обновления сохраните текущие параметры в `.nexus` через «Проекты и копии». Картинку держите отдельным исходным файлом: неудачная загрузка её на часы не сохраняет.
2. Установите `NEXUS_OS_6_7_0/NEXUS_OS_6_7_0.ino`, все заголовки оставьте рядом. Сначала используйте прежние рабочие настройки платы, USB и разделов. PSRAM включите в режиме, соответствующем вашему модулю. Закройте Serial Monitor.
3. Откройте новую студию из этого комплекта, подключитесь, перейдите в «Оформление». Новая строка хранилища покажет причину.
4. Если файловый раздел существует, но не подготовлен, нажмите «Подготовить хранилище фона» и подтвердите удаление файлов только этого раздела. Это явное действие: при загрузке прошивки/старте автоматического форматирования нет. Затем снова выберите картинку и примените оформление. Картинка, уже подготовленная в редакторе, сохраняется там и после ошибки.
5. Если раздела нет, кнопка подготовки отключена: форматирование не создаёт таблицу разделов. В Arduino IDE, Tools / Инструменты → Partition Scheme / Схема разделов, выберите схему с файловым разделом SPIFFS не меньше 512 КБ и достаточно большим разделом приложения для вашей сборки. LittleFS использует раздел с меткой `spiffs`, несмотря на название SPIFFS в меню. Загрузите прошивку заново с новой таблицей, затем выполните шаг 4.
6. Если памяти для фона недостаточно, сначала сохраните текущий фон и проект. Можно удалить старый фон кнопкой студии и попробовать загрузку заново; для постоянной работы предпочтителен файловый раздел от 512 КБ. Безопасная запись хранит новый и предыдущий фон одновременно.
7. Включите «Использовать загруженный фон». Установите «Видимость фона» выше 0%; для проверки удобно 70–100%. Нажмите «Применить раздел». Успех означает получение ACK и проверку размера/CRC сохранённого файла, а не только красивый предпросмотр.

Не задавайте размер flash больше физического объёма платы. Изменение таблицы разделов может затронуть прежние данные; сначала сделайте копию. Не выполняйте полную очистку flash просто для проверки картинки.

## Проверка мигания

В «Диагностике» нового выпуска проверьте строку «Буфер отрисовки»: должно быть «Включён». Если указано «Недоступен — проверьте PSRAM», часы используют запасной прямой режим. Уточните рабочий режим PSRAM для своего модуля в настройках Arduino и загрузите прошивку снова. Ошибка выделения буфера сама по себе не вызывает бесконечные перезапуски.

Старый код каждую секунду заново передавал фон на дисплей, затем последовательно дорисовывал цифры и карточки. Теперь всё собирается вне дисплея и показывается готовым кадром; управление включением/выключением LCD идёт непосредственно к физическому дисплею. Чистые кадры не отправляются заново в каждом проходе loop. Полное обновление кадра по SPI всё равно занимает время; реальная плавность и возможные разрывы развёртки ещё требуют проверки на плате.

Без секунд циферблат обновляется реже. Выключение секунд можно использовать как дополнительную экономию, но оно не заменяет буферизацию и подготовку хранилища.
