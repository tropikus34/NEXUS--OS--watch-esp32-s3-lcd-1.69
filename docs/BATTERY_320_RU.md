# Аккумулятор 320 мА·ч: профиль и ограничения зарядки

NEXUS OS 5.9.2, 29 октября 2026. Плата Waveshare ESP32-S3-LCD-1.69 V2.

## Что реализовано

- Задан номинальный профиль 320 мА·ч. Это значение сообщил пользователь; оно не измеряется автоматически.
- Значение сохраняется в NVS отдельным версионированным ключом bat_cap. Перезапуск сохраняет профиль. При отсутствии корректного профиля используется 320 мА·ч.
- Экран «Устройство» показывает заданную ёмкость и измеренное напряжение. Процент в шапке по-прежнему приблизительный и помечен ~.
- Экран явно сообщает «Зарядка: нет данных». Команда NXBATTERY сообщает CHARGING=UNKNOWN, FULL=UNKNOWN, CHARGE_CONTROL=HARDWARE.
- NXCAPACITY 320 сохраняет номинальную ёмкость. Допустимый диапазон профиля 10–10000 мА·ч — только диапазон хранения данных; он не означает совместимость аккумуляторов с платой.
- Изменение ёмкости не меняет зарядный ток, напряжение зарядки, GPIO, I2C или питание SYS_EN. Не добавляется расчёт якобы измеренных оставшихся мА·ч или точного времени до полного заряда.

## Почему прошивка не может «заряжать до полного»

На официальной схеме V2 зарядкой занимается ETA6098. Её вывод STAT не соединён с GPIO процессора; у схемы нет подключённого к ESP32 интерфейса задания зарядного тока. BAT_ADC через делитель R3=200 кОм / R7=100 кОм измеряет напряжение B+, а не ток и не ёмкость. В программе сохранён коэффициент делителя 3,0; точность требует проверки мультиметром.

ETA6098 сама выполняет заряд CC/CV и завершение, рассчитана на соответствующий Li-ion элемент с конечным напряжением 4,2 В. Порог уменьшения тока при завершении по документации — 130 мА. Прошивка не должна удерживать зарядку, обходить завершение или рисовать подтверждённое «Полностью заряжено» только по напряжению.

## Важная совместимость с маленьким аккумулятором

На официальной схеме установлен R25=82 кОм на ISET. По документации ETA6098 это номинальная настройка 2 А. Для 320 мА·ч 2 А соответствует 6,25C. Фактическая установленная деталь/ревизия платы и допустимый ток аккумулятора ещё не проверены. Нельзя считать такой режим допустимым для данного аккумулятора без его спецификации.

До проверки реальной платы и допустимого режима элемента не заряжайте этот аккумулятор через эту плату. Для прошивки/работы от USB отсоедините аккумулятор. Файл обновления не делает аппаратную зарядку безопаснее и не ограничивает её ток.

Нужно проверить фото платы с обеих сторон, номинал R25/маркировку зарядной микросхемы и маркировку/спецификацию аккумулятора. Даже уменьшение тока одним резистором без проверки порогов предварительного заряда и завершения не является подтверждённым решением для маленькой ячейки. Настоящая настройка зарядки потребует подходящего аппаратного зарядного узла и допустимых параметров конкретного элемента.

## Проверки

Пройдены программные проверки: профиль 320 мА·ч, сохранение/загрузка NVS, отсутствие/ошибка профиля, отказ записи без изменения RAM, валидация USB, корректное «неизвестно» для состояния зарядки и полного заряда, отсутствие операций управления зарядкой. Пройдены регрессии интерфейса, кнопки, сообщений, будильников/таймера, активности и редактора тем.

Сборка настоящим Arduino-ESP32 и проверка на физической плате здесь не выполнены. Номинальная ёмкость не подтверждает реальную остаточную ёмкость старого элемента. Четыре дня автономности не подтверждены измерением.
