# NEXUS OS 5.8.0 — PRISM UI

Обновление интерфейса для Waveshare ESP32-S3-LCD-1.69 V2, ST7789 240×280 и одной кнопки BOOT. Семь тем и семь специализаций сохранены. Добавлены категории настроек, обратная навигация, понятные состояния и перенос слов в уведомлениях.

## Установка

Распакуйте архив. Откройте `NEXUS_OS_5_8_0/NEXUS_OS_5_8_0.ino`. Все `.h`, включая новый `NexusNavigation.h`, должны оставаться рядом с `.ino`. Нужны прежние Arduino-ESP32, Arduino_GFX_Library, ChronosESP32 и совместимая NimBLE-Arduino 2.x. Wire, LittleFS и FreeRTOS входят в Arduino-ESP32.

Сохраните рабочие параметры своей платы, памяти, PSRAM и разделов. Очистка NVS и форматирование LittleFS для этого обновления не требуются: формат сохранённых настроек не менялся. Резервную рабочую прошивку оставьте у себя.

## Одна кнопка

| Где | Один клик | Двойной клик | Удержание около 700 мс |
|---|---|---|---|
| Просмотр страниц | Следующая страница | Предыдущая страница | Открыть действие, указанное внизу |
| Разделы настроек | Следующий раздел | Предыдущий раздел | Открыть выбранный раздел |
| Редактирование | Увеличить / переключить | Уменьшить / действие с подписью | Следующее поле, на последнем сохранить |
| Чтение сообщений | Следующая страница текста | Следующее более старое сообщение | Вернуться к просмотру |
| Погашенный экран | Разбудить экран | — | Первое нажатие только пробуждает |
| Всплывающее сообщение / сигнал | Закрыть / остановить | — | Нажатие поглощается окном |

Чтобы отличать одиночное нажатие от двойного, одиночный клик выполняется после окна 300 мс. Удержание срабатывает один раз и не отправляет принудительно на циферблат.

Основной круг: часы → активность → будильники/таймер → сообщения → настройки → устройство → дата и время. Двойной клик идёт в обратную сторону. Удержание на циферблате открывает инструмент специализации, на активности — личный профиль, на устройстве — быстрый выбор темы/специализации.

## Разделы настроек

На странице «Настройки» удержать кнопку, выбрать раздел одним/двойным кликом и удержать для входа:

| Раздел | Поля |
|---|---|
| Экран | Яркость, время гашения, формат времени, мигание точек |
| Стиль | Тема, специализация, свой фон, компоновка своей темы, удаление фона |
| Телефон | Автоподключение, окно подключения, забыть телефон |
| Сообщения | Не беспокоить, без звука, приватность, тест, очистка |
| Активность | Рост, вес, длина шага, чувствительность, цель, интервал разминки, напоминания, подсчёт |
| Энергия | Режим экономии |
| Ваше имя | Восемь символов имени часов; имя BLE обновляется после перезапуска |
| Дата и время | Часы, минуты, день, месяц, год |
| Назад | Выход к обычным страницам |

После последнего поля возврат в выбранный раздел. На экране указаны номер поля и общее число полей этого раздела. В действиях удаления, очистки и подключения выполнять команду нужно двойным кликом, как указано на экране; удержание только проходит дальше/завершает.

## Внешний вид

Одинаковая сетка и управление действуют во всех семи темах. Меняются палитра, радиус карточек и характер циферблата. Выделение обозначено рамкой и маркером, а не только цветом. В приложениях в шапке видно текущее время. На главной странице видны непрочитанные сообщения; дополнительный показатель отдаёт приоритет запущенному таймеру, затем непрочитанным сообщениям.

В разделе будильников видна полоса `1 2 3 4 5 Т`: пять сохранённых будильников и таймер. Удержать для настройки, на первом поле выбрать нужный слот коротким/двойным нажатием, затем удерживать для перехода к часам, минутам и состоянию.

Фоновая картинка на циферблате дополнительно смешивается с фоном темы (25% картинки / 75% фонового цвета) для читаемости. Исходный файл картинки не перезаписывается. USB Theme Studio обновлён для 5.8.0; его браузерное изображение приблизительное, точные программные рендеры находятся в папке Preview.

## Проверки

Пройдены C++ проверки с заменителями оборудования: прежние функции, физическая последовательность короткого/двойного нажатия через настоящий обработчик кнопки, удержание, полный охват параметров категориями, сохранение/возврат, состояния уведомлений и сигналов, UTF-8 и перенос слов, семь тем. Пройдены проверки шагомера/профиля/напоминаний, протокола передачи фона и JavaScript Theme Studio. Использованы ASan и UBSan. Проверен минимальный расчётный контраст основных текстовых ролей семи RGB565-палитр; это не измерение реального дисплея на солнце.

Сборка настоящим Arduino-ESP32, проверка на физических часах, измерение плавности и автономности ещё необходимы. Семь дней работы не подтверждены. Данные на изображениях — демонстрационные. Вибрация по-прежнему требует внешнего мотора с драйвером, по умолчанию используется зуммер. Подробности активности и оценки калорий — в Reference/Activity_5_7_RU.md; при различиях навигации действует текущая инструкция.

Из корня архива на Linux:

```sh
python3 tests/run_checks.py
```
