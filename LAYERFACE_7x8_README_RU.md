# NEXUS LayerFace v1: редактор пользовательских циферблатов

## Что включено

- В существующую `NEXUS_Studio.html` добавлена вкладка **Мои циферблаты**.
- Выбор исходника: 7 коллекций × 8 вариантов (56 комбинаций).
- **Создать свою тему** создаёт независимый векторный проект, не затрагивая встроенные циферблаты.
- Редактирование непосредственно на холсте: касание/перетаскивание, выделение слоя, координаты, размер, цвет, видимость, тип, источник данных, толщина, угол/дуга.
- Типы: надпись, дуга, индикатор-шкала, залитый прямоугольник, контур, круг, значок, стрелка.
- Источники: время, часы, минуты, секунды, дата, батарея, шаги, приблизительные калории, BLE, сообщения, владелец, таймер, цель шагов, произвольная надпись.
- Экспорт проекта `.json` (повторно редактируемый) и бинарного `.nxlf`; загрузка по USB и возврат к штатному циферблату.
- Новый `NexusLayerFace.h`: проверка данных, CRC при передаче, стадийный файл в LittleFS, резервная копия, ограничение до 16 слоёв. Базовые циферблаты, часы, BLE, OSD, энергосбережение не удалены.

## Важно про точность шаблонов

Встроенные 56 вариантов ранее рисовались программным кодом. В этой версии редактора создано **56 векторных приближений/производных шаблонов**, а не покомпонентная декомпозиция каждого пикселя оригинального встроенного циферблата. Визуальные элементы editable-проектов могут отличаться от встроенных оригиналов, особенно сложные шрифты и эффекты. Невозможно обещать побуквенное сохранение сложной графики при таком переходе без дополнительного портирования каждого оригинального слоя.

## Как пользоваться

1. Откройте `NEXUS_Studio.html` в Chrome/Edge (для USB нужен Web Serial и поддерживаемый контекст; обычно HTTPS или localhost, `file://` зависит от браузера).
2. Откройте «Мои циферблаты», выберите коллекцию и вариант, нажмите «Создать свою тему».
3. Выделите объект и перетащите его. В панели можно менять его свойства или добавлять свои объекты.
4. Сохраните `.json` как исходный проект. `.nxlf` служит только для прошивки и **не является редактируемым проектом**.
5. Прошейте часы прошивкой из этого архива после успешной компиляции в вашей среде. В студии подключитесь по USB и нажмите «Загрузить на часы».
6. Для удаления пользовательского циферблата нажмите «Вернуть стандартный циферблат».

## Технические ограничения / безопасность

- Формат NXLF v1: 10-байтный заголовок и 24 байта на слой, не более 16 слоёв.
- X: 0..239, Y: 0..255 (в протоколе один байт), объект не должен выходить за 240×280.
- Метки не более 12 байт UTF-8. Для длинных русских подписей требуется расширение формата; сокращайте подписи.
- Редактор тем и существующий редактор OSD работают раздельно. При наличии активной пользовательской темы она имеет приоритет на экране часов, пока не будет удалена. Другие экраны часов не меняются.
- Темы хранятся в LittleFS, требуется FS-раздел; перед передачей `NXLFINFO` должен вернуть `VERSION=1` и `FS=1`.
- Завершение команды `NXLFEND` подтверждает лишь сохранение файла. После перезагрузки он загружается автоматически, если валиден структурно.
- Для ZIP внесено исправление `src_dir` в `platformio.ini`, перенесено в `[platformio]`. Используется pioarduino + Arduino/ESP-IDF, как и в исходном проекте. Сборка этой версии локально не выполнена, работоспособность на реальной плате не подтверждена.
- При отсутствии файла или неверном содержимом система отображает штатный циферблат. Операция замены использует временный файл и резервную копию, но аппаратная устойчивость к внезапному отключению питания не испытана.
- Калории показываются грубой оценкой по шагам, **не медицинским измерением**.

## Команды прошивки

- `NXLFINFO` → `LFINFO VERSION=1 ACTIVE=... COUNT=... FS=... MAX=16`
- `NXLFBEGIN <bytes> <crc32hex>` → `OK LFREADY`
- `NXLFCHUNK <offset> <hex>` → `OK LFCHUNK` (до 64 байт на сообщение)
- `NXLFEND` → `OK LFSTORED`
- `NXLFDELETE` → `OK LFDELETE`

Не используйте `NXFORMAT` для установки пользовательской темы: форматирование стирает содержимое файловой системы, включая фото-фон.
